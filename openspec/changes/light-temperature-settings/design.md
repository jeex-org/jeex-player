# Design

## Context

See proposal.md and brainstorm.md. Today's colours: hemisphere sky `#fffcf6`, ground `#6d675f`, sun `#fff4e6`, fill `#bed7de`, bank lamps `#ffd9a4`. The walk grid bake hides furniture (lamps included) and zeroes fill, hemisphere and the ambient floor. The control bar is centred and shrink-wrapped with 4 px gaps. `render-runtime.ts` is near its line limit and `viewer-app.ts` at 500: new logic goes into new modules.

## Decisions

1. **Standard**: `LIGHTING_STANDARD.temperature = { min: 2700, max: 6500, step: 100, default: null }`; `src/lighting/colour-temperature.ts` (pure, exported from the lighting entry): kelvin → unit-luminance linear RGB by Helland (t = K/100; R = 255; G = 99.4708025861·ln t − 161.1195681661; B = 138.5177312231·ln(t − 10) − 305.0447927307; clamp, /255, sRGB decode, divide by Y). Version stays 1. The entry's size budget is re-measured by its own rule if it grows.
2. **Applying it**: a player module `src/render/light-temperature.ts` owns the current value and applies it to every artificial light: the bank's `buildLamp`, `buildPendant` and `buildCeilingLight` gain a tag on their point lights, `userData.artificialLight = { colour }` holding the original colour (the builders change by one line each), and the walk ambient floor; colour = unit colour × the original colour's luminance; «Original» restores the stored colour exactly. The applier runs on every new root and model swap (scene-mount hooks) and on the offscreen scene of default-state captures, so later and offscreen lamps get the value. Tests use the real bank builders. In walk and tour, after the value settles (250 ms after the last input), the room probes are re-captured one room per frame, each written into the atlas in place and invalidating the on-demand gate; grids are never re-baked (their input excludes these lights today). A colour change invalidates the gate at once.
3. **Sun factor** (a test pins the new anchor in the r186 directional-light loop and that editing and capture states render identically to before): in the walk shader patch, locate the fragment's room before the directional-light loop and scale the sun's `directLight.color` by `mix(1, walkSunScale, inRoom)` (fill is already 0 in walk); `walkSunScale = 1/3.5` in the walk tuning; the editing and capture states pass 1. Measure the sunlit floor's peak and texture before and after.
4. **Panel**: `src/ui/settings-panel.ts` and its CSS over `--jeex-*` tokens; the button is an extension element in its own wrapper, positioned absolutely at the bar's end edge so the bar's centring ignores it; at the narrow breakpoint (the bar spanning the viewer between its 10 px insets, ≤ 430 px viewer width by container query) it sits directly above the bar's end inside the viewer; mutual exclusion with the «Interior style» panel; initial focus on the slider; outside press listened on the document; native `<input type="range">` (thumb at 4000 K while «Original»; first adjustment leaves «Original») with translated `aria-valuetext`, an `<output>`, an «Original» button, a Close button; `aria-expanded` on the button; Escape, outside press, focus return; keeps chrome awake; no `showModal()`. Strings in `src/shared/messages.ts` and all six other catalogues.
5. **Contract** (shapes in spec «Setting and reporting the temperature»): an invalid value from the handle throws `bad-option`; from an attribute or query it warns once and keeps the current value (not the resolver's default); attribute removal means «Original»; no event on an unchanged value. options in `viewer-options.ts`/`.schema.ts`/`option-sets.ts`/resolvers (a bounded nullable temperature kind), attributes live in the element, query parameters in the demo parser, handle method and state, `lightTemperatureChange` in `viewer-events.ts`, iframe command and event schemas, bridge and host methods (additive). The local demo enables `settings`.
6. **Persistence**: host configuration; the editing host saves per project and passes it to published embeds. No scene change.

## Risks / Trade-offs

1. [Lamps of the built-in bank are the only artificial lights today; a room without bank lamps changes only through the walk ambient floor] → honest by design; the lamp step brings descriptor lamps under the same control.
2. [Probe re-capture after a change costs frames in walk] → budgeted, after a 250 ms settle.
3. [The attached button must not shift the centred bar] → a layout test compares control positions with and without the button.
