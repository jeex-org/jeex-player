Options are attributes, events are CustomEvents, and the viewer lives in an open shadow root. The buttons below change the two attributes that stay live after the mount — view and src — and the third one takes the element out of the DOM, which disposes it.

The compound chrome attribute is all: unset for the five chrome.* flags — this element does not use it (its own chrome stays live for the buttons above), but a host that wants everything hidden except one flag writes it as one attribute plus the override, no :global CSS needed: <jeex-viewer chrome="false" chrome-status="true">. See the "compound chrome attribute" tests in tests/component/element.test.ts and tests/e2e/embed-element.spec.ts for it exercised end to end.
